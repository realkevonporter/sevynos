# Support

SevynOS is experimental and community-supported.

Use GitHub Discussions for setup questions, design conversation, and general
help. Use GitHub Issues for reproducible defects. Include the SevynOS revision,
host or hardware model, firmware mode, exact command, expected behavior, actual
behavior, and sanitized logs.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md). For community
conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
