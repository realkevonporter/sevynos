SevynOS Principles v0.1
1. Users Own Their Devices
The device belongs to the user—not SevynOS.
Users should be able to:
Install any software
Replace any system app
Unlock every developer feature
Access the file system
Customize every aspect of the experience
No artificial restrictions.
2. Developers Come First
The best platform is the one developers love building for.
Goals:
TypeScript first
React Native first-class
Excellent documentation
Incredible tooling
Simple APIs
3. Open by Default
Whenever possible:
Open standards
Open APIs
Open source
If something must be closed, there needs to be a very good technical reason.
4. Simplicity Wins
Every feature must answer:
Does this make the platform simpler?
If not…
Remove it.
5. Performance Matters
Beautiful software that feels slow…
isn't beautiful.
Everything should feel immediate.
6. Privacy is the Default
Users shouldn't have to hunt through settings to protect themselves.
Privacy should be automatic.
7. One Codebase
This one is your superpower.
Developers should be able to write one application and target:
Phones
Tablets
Watches
TVs
Cars
Desktop
Embedded devices
from the same project.
8. Freedom Over Lock-in
Users should never feel trapped.
If they want to leave SevynOS:
They should be able to.
If they want to customize SevynOS:
They should be able to.
If they want to build SevynOS:
They should be able to.
Our Engineering Philosophy
This is one I want us to repeat constantly:
Never reinvent a solved problem. Innovate only where it creates real value.
Linux already solved kernels.
LLVM solved compilers.
Git solved version control.
React Native solved cross-platform UI.
We'll stand on the shoulders of giants instead of rebuilding everything from scratch.
What I think will make SevynOS different
Earlier, something clicked for me.
At first we were talking about "building another operating system."
I don't think that's actually what SevynOS is.
I think SevynOS is a computing platform.
Phones are just one device.
Imagine this future:
You buy a laptop running SevynOS.
Your watch runs SevynOS.
Your phone runs SevynOS.
Your TV runs SevynOS.
Your Raspberry Pi runs SevynOS.
Your car dashboard runs SevynOS.
Every device shares the same APIs.
The same design language.
The same app model.
The same developer tools.
The same TypeScript experience.
That's much bigger than "another phone OS."
