# Beyond Genesis

The long-term vision is a coherent, user-owned computing platform across
desktop, phone, tablet, television, wearables, vehicles, embedded boards, and
devices that do not exist yet.

Long-range directions include:

- one compatible React Native application model across form factors;
- replaceable system applications and transparent capability controls;
- open hardware reference profiles;
- secure, signed, user-controlled updates and recovery;
- self-hostable synchronization and services;
- accessibility and assistive intelligence designed into the platform;
- a mature SDK, application distribution model, and contributor ecosystem.

These are directions, not release promises. Near-term work and acceptance
criteria belong in [Phase 1: Genesis](phase-1.md).
