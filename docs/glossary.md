# SevynOS glossary

- **Genesis** — the first SevynOS architecture and desktop implementation.
- **Runtime** — the policy authority for applications, sessions, and lifecycle.
- **Graphics** — host-independent display, composition, rendering, surface, and
  window behavior.
- **Host** — an adapter that connects SevynOS contracts to a platform or
  execution environment such as Electron, Linux, JavaScript, or React Native.
- **Framework** — host-independent application-authoring support.
- **Shell** — the system-owned user environment composed from public platform
  capabilities.
- **Surface** — renderable application content associated with an application
  session and, when visible, a window.
- **Application session** — one runtime-managed execution of an application
  package.
