The SevynOS Manifesto (Draft)

We believe users should own their devices.

Not rent them.
Not lease them.
Not ask permission to use hardware they purchased.
Ownership should mean ownership.

We believe developers deserve better.

Building software shouldn't require maintaining multiple codebases for the same application.
One application.
Multiple devices.
Minimal friction.
We believe openness creates innovation.
Open platforms outlive closed platforms because thousands of people can improve them.
The best ideas can come from anyone.

We believe software should be understandable.

Complexity is sometimes necessary.
Confusion is never the goal.
If something can be made simpler without sacrificing capability, it should be.

We believe freedom and polish can coexist.

You shouldn't have to choose between:
beautiful software
powerful software
You deserve both.

We believe operating systems should empower, not restrict.

Technology should expand what people can do.
Not tell them what they aren't allowed to do.
