# Sevyn Design Language

Sevyn Design Language is the visual and interaction foundation for Genesis system applications. It is original to SevynOS: it does not use Apple assets, symbols, layouts, window controls, wallpapers, sounds, or proprietary visual elements.

## Character

Sevyn interfaces are calm, dimensional, precise, and personal. Hierarchy comes from spacing and typography before decoration. Translucent materials create context without hiding structure; rounded geometry remains architectural rather than pill-shaped. Gold is the signature accent, while user-selected accents remain first-class.

The canonical tokens live in `frameworks/react-native/src/tokens.ts`. They define semantic light and dark colors, type roles, spacing, radii, borders, shadows, material opacity and blur, motion timing, spring behavior, cursor sizing, and focus treatment. Reduced motion resolves nonessential animation durations to zero without changing lifecycle outcomes.

## Portable surface pipeline

System applications compose immutable `NativeApplicationSurfaceSnapshot` values. Snapshots contain deterministic material, text, icon, separator, and control commands plus semantic hit regions. They contain no Canvas, DOM, Electron, filesystem, or Linux API references.

The desktop path is:

`system application → Sevyn native surface → DesktopSceneComposer → DisplayRenderPlanner → GenesisFrameExecutor → CanvasGenesisRenderer`

The Linux host can execute the same snapshots with a different host renderer. Input and lifecycle ownership remains in the SevynOS runtime and application coordinator.

## Icons

The initial Sevyn icon grammar uses simple original geometric strokes: split discs, diamonds, nested workspaces, flowing motion paths, and directional pointer forms. Icons are generated by the host renderer from semantic icon names; no traced or third-party symbol assets are included.
